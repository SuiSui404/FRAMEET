# FRAMEET · 视频截图拼壁纸

把心动的一帧留在桌面上。

看MV、舞台、影视剧或4K视频时，总有一些画面美到忍不住库库截图。FRAMEET让你在浏览器里边欣赏视频边随手留下喜欢的一帧，看完后随手整理照片、添加文字和贴纸，2分钟即可导出自己专属的桌面壁纸（支持电脑/手机/iPad多种尺寸），免去在截图文件夹和拼图软件之间来回操作、多图排版和后续清理相册的烦恼。

FRAMEET = Frame × Meet，让视频里遇见的画面，在桌面上反复重逢。

制作：@传闻中的穗穗

## 当前版本

v0.9.4。支持桌面版Chrome / Microsoft Edge，使用Manifest V3，Chrome最低版本116。扩展商店上架流程进行中；获得正式商店链接后会更新本页。

下载：[FRAMEET v0.9.4 ZIP](https://github.com/SuiSui404/FRAMEET/raw/main/dist/FRAMEET-v0.9.4.zip)。解压后包含可加载的manifest.json、脚本与资源。

## 本地安装

1. 下载Release ZIP并解压到固定目录。
2. Chrome打开`chrome://extensions`，Edge打开`edge://extensions`。
3. 启用开发者模式，选择“加载已解压的扩展程序”，选择包含manifest.json的目录。
4. 打开普通视频网页，点击工具栏FRAMEET图标启用截图工具和侧栏。
5. 截图后进入“制作壁纸”，选择版式、整理照片、编辑文字与贴纸，导出PNG。

也可直接加载本仓库的`extension/`目录。更新现有解压版时保留原目录并重新加载，避免先卸载导致数据丢失。

## 能做什么

- 视频随便看，每帧随手截：点击插件图标启用后，浏览器右下角一键截取当前视频帧，支持多只视频的截图放在同一个壁纸项目中。
- 多图随意排：三种版式，装下不同的心动。胶片风+拍立得+简单拼接。多图支持按色系排序，便于快速排版，支持导入自己的图片作为背景和拼图素材。亦可添加手写文字、相纸附文和贴纸。支持多个壁纸项目，随时切换继续制作。
- 壁纸随心换：电脑、手机、iPad分级尺寸选择，PNG无水印导出；打开已关闭或已导出的旧壁纸项目，所有截图仍在库中，随时一键更换排版或拼图素材，直接导出，比官方出图还快。素材、项目和编辑内容保存在当前浏览器本机，不上传到开发者服务器。当前版本无需注册账号，无广告。

## 隐私与存储

截图、项目、来源网页的URL/标题和编辑内容保存在当前浏览器扩展的本地IndexedDB中。当前版本不向开发者服务器上传数据，无账号、广告、统计SDK或云同步。所需权限只有activeTab、sidePanel、scripting。

完整隐私政策：[公开隐私页面](https://suisui404.github.io/FRAMEET/privacy/)，对应源码`docs/privacy/index.html`。

删除照片会保留在“已删除”分类供恢复；删除整张壁纸才会清除该项目的当前与已删除照片。下载出的PNG由用户在下载目录管理。不同扩展ID、浏览器或设备之间的数据不会自动迁移。

## 使用范围

部分嵌入式播放器、受保护视频、跨域环境或浏览器内部页面可能限制截图；不承诺支持所有网站，不绕过访问控制。请按素材来源和相应授权使用截图及导出作品。
